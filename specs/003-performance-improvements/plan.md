# Implementation Plan: Performance Improvements

**Branch**: `003-performance-improvements` | **Date**: 2026-03-26 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/003-performance-improvements/spec.md`

---

## Summary

Add three performance improvements to gphotos-sync:

1. **Skip existing photos** (P1 — MVP): Before downloading each photo, check if it already exists on disk (non-zero bytes). Skip if present; re-download only with `--force`. Adds a "Skipped" count to the run summary.
2. **Parallel downloads** (P2): `--workers N` flag enables concurrent within-date downloads using `concurrent.futures.ThreadPoolExecutor` with per-thread Playwright instances.
3. **Early scroll exit** (P3): Scraper already exits after 3 stable cycles (`no_new_count >= 3`); this feature tightens adaptive timing to reduce dead-wait time.

Cross-cutting: Pre-flight stage (folder creation + file inventory) runs before browser open. Each stage logs its elapsed time.

## Technical Context

**Language/Version**: Python 3.9+
**Primary Dependencies**: `playwright>=1.40.0` (existing), `pyyaml` (existing); `concurrent.futures` and `time` (stdlib — no new pip dependency)
**Storage**: Local filesystem only
**Testing**: `pytest`
**Target Platform**: Windows 11 (primary), Linux/macOS (supported)
**Performance Goals**: Repeat sync of fully-downloaded date < 10s; 2× speedup with `--workers 4` on 30-photo dates
**Constraints**: No new third-party dependencies; Python 3.9+ only; `--profile all` remains strictly sequential
**Scale/Scope**: Typical: 10–200 photos/date; up to 8 parallel workers

## Implementation Phases

### Phase 1: Config + Data Model (foundation)

**Files**: `src/config.py`, `src/downloader.py`

1. Add `force: bool = False` and `workers: int = 1` to `SyncConfig`.
2. Add `--force` and `--workers` to `parse_args()`; validate `workers >= 1`.
3. Add `skipped: int = 0` and `stage_times: dict` to `SyncRun`.
4. Update `per_day` tuple from `(dl, fail)` to `(dl, skip, fail)`.

### Phase 2: Pre-Flight Stage (FR-009, SC-006)

**File**: `src/downloader.py`

1. Implement `_preflight(dates, destination, force) -> dict[date, set[str]]`:
   - Creates `YYYY/MM/DD/` for each target date.
   - Returns `{date: frozenset_of_existing_filenames}` (empty set if `force=True`).
   - Times this stage with `time.monotonic()`; logs elapsed at INFO.
2. Call `_preflight()` in `run_sync()` **before** `browser.ensure_session()`.

### Phase 3: Skip Detection in Scraper (FR-001, FR-004, US1)

**File**: `src/scraper.py`

1. Update `download_photos_for_date(context, target_date, destination, verbose, existing_files, force)` signature — accept pre-built `existing_files: set[str]` from pre-flight.
2. In `_download_one()`: navigate to photo URL, call `page.title()`, strip ` - Google Photos`, check against `existing_files`. If skip-eligible, close page and return `(filename, "skipped")`.
3. Update callers and return value to `(downloaded, skipped, failed)`.
4. Update `download_photos_for_date` to time the collection and download stages separately.

### Phase 4: Parallel Downloads (FR-005, FR-006, US2)

**File**: `src/scraper.py`

1. Add `_download_parallel(photo_urls, dest_dir, state_file, verbose, existing_files, workers)` using `ThreadPoolExecutor`.
2. Each worker: `sync_playwright().start()` → `browser.launch(headless=True)` → `context.new_context(storage_state=state_file)` → `_download_one_in_context(context, url, ...)` → close context, stop pw.
3. Thread-safe counter accumulation via `threading.Lock` or by collecting futures' return values.
4. `download_photos_for_date` routes to `_download_parallel` when `workers > 1`, else existing sequential loop.

### Phase 5: Output + Logging Updates

**File**: `src/photo_sync.py`

1. Update `print_summary()` to show "Skipped: N" line between Downloaded and Failed.
2. Add `~` verbose prefix for skipped photos.
3. Update date-range multi-day table to include Skipped column.

### Phase 6: Tests

**Files**: `tests/unit/test_config.py`, `tests/unit/test_downloader.py`, `tests/unit/test_scraper.py`

- Config: `--force` sets `force=True`; `--workers 4` sets `workers=4`; `--workers 0` exits 2.
- Downloader: `_preflight()` creates folders and returns correct existing-file sets; `force=True` returns empty sets.
- Scraper: skip detection returns correct `(dl, skip, fail)` counts; zero-byte file treated as missing.
